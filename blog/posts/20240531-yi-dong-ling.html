移动零

题目概述

https://leetcode-cn.com/problems/move-zeroes/">题目链接：283.移动零
给定一个数组 nums，编写一个函数将所有 0 移动到数组的末尾，同时保持非零元素的相对顺序。
请注意 ，必须在不复制数组的情况下原地对数组进行操作。

示例 1:

  • 输入: nums = [0,1,0,3,12]
  • 输出: [1,3,12,0,0]

示例 2:

  • 输入: nums = [0]
  • 输出: [0]

思考

方法一：暴力法

第一版思考还是比较简单的，直接遍历数组，遇到0就删除，然后在数组末尾添加一个0，直到遍历结束。
下面是错误解法：
``void moveZeroes(int* nums, int numsSize) {
for(int i = 0; i < numsSize;i ++)
{
if(nums[i] == 0)
{
for(int j = i;j < numsSize - 1;j++)
{ nums[j] = nums[j + 1];
}
nums[numsSize - 1] = 0;
}
}
}`结果发现提交不过...检查之后发现，当数组中存在连续的0时，删除一个0后，后面的0会往前移动，导致漏掉一些0。
并且这样做时间复杂度还是高的，因为最后都是0，所以也没必要再遍历一遍了。
继续修改，让数组的实际操作长度动态变化，也不一定非要使用for循环遍历，手动操作下标会更好一些。
win！改完后一次通过。
`void moveZeroes(int* nums, int numsSize) { int cur_len = numsSize; int i = 0; while(i < cur_len) { if(nums[i] == 0) { for(int j = i;j < cur_len - 1;j++) { nums[j] = nums[j+1]; } nums[cur_len - 1] = 0; cur_len --; } else { i ++; } }}``时间和内存使用情况如下图所示：

方法二：双指针

正如这道题目的分类所述，双指针法是这道题目的最佳解法。
说是双指针，其实本质上还是操作数组，只不过思路有一定变化，上一种枚举法是对于每一个元素都进行遍历，这不由得想到排序算法中的冒泡排序，冒泡排序就是对于每一个元素都进行两两比较，如果顺序不对就交换位置。
而双指针法则是将数组分为两个部分，一部分是非零元素，一部分是零元素，由于零元素都在末尾，所以把非零元素找完了，剩下的就是零元素了。而找零元素的时候就采用前序遍历，如果不是0就往前复制，如果是0就跳过，如果后面有非0的元素，就会覆盖前面的0。
那么具体实现就是：
```void moveZeroes(int* nums, int numsSize) { int no_zero_index = 0; int i = 0; for(i = 0;i < numsSize;i++) { if(nums[i] != 0) { nums[no_zero_index] = nums[i]; no_zero_index++; } }

for(i = no_zero_index;i < numsSize;i++) { nums[i] = 0; }}```
这里有心机地把变量i的定义写在了for循环外，这样能够减少内存的消耗（也没多少，只是满足指标的虚荣心（笑））。看一下时间和内存使用情况以及时间复杂度吧：

## 题目
[反转链表题目链接](https://leetcode.cn/problems/reverse-linked-list/?envType=study-plan-v2&envId=top-100-liked)

## 解法
反转链表是个经典题型，主要是利用到单向链表的特性，如果第一次做没做出来也正常(me too~)，因为链表的特性比较特殊，还是要掌握适当的方法才能够更好的掌握链表相关的。  
先看代码：
```
struct ListNode* reverseList(struct ListNode* head) {
    struct ListNode* new = NULL;
    struct ListNode* cur = head;
    while(cur != NULL)
    {
        //保存下一个节点信息
        struct ListNode* next = cur->next;
        cur->next = new;
        new = cur;
        cur = next;
    }
    return new;
}
```
再看分析过程，记住上面的几个结构体指针new cur next。  
首先我的思路和常规的理解不太一样，我们从链表的本质出发  
链表最常见的操作就是插入和删除，以删除举例，就像是离职交接工作一样，分两步走： 
第一步：首先让指向杰哥的同事去指向杰哥指向的同事，听起来很绕口吧~可以想象一下，当你要离职的时候，有个同事A来找你，你就会说：“你去找B去！我辞职了！”，这个时候，就会从A->你->B，多出一个A->B。这就是交接的动作。  
第二步：你不再指向B，而是指向新公司的C，这样就完成了所有离职的手续，并加入了新公司。  
这就是本题的思路。
